# DecodeLabs Week 1 — Data Cleaning and Preparation

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship. The objective was to clean and prepare an e-commerce order dataset for further analysis.

## Dataset

- Records: 1,200
- Columns: 14
- Dataset Type: E-commerce order data

The dataset contains information about orders, customers, products, prices, payment methods, order status, tracking information, referral sources, and total prices.

## Data Cleaning Tasks

The project focused on checking and preparing the dataset for analysis, including:

- Missing value analysis
- Duplicate record checking
- Incorrect data checking
- Date format checking
- Numerical format checking
- Text format checking
- Overall data consistency

The cleaned dataset was exported to an Excel file for use in the next stage of analysis.

## Tools Used

- Python
- Pandas
- Microsoft Excel
- Python IDLE
