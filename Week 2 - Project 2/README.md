DecodeLabs Internship – Project 2

Exploratory Data Analysis (EDA)

📌 Project Overview

This project was completed as part of the DecodeLabs Data Analyst Internship. The objective of this project was to perform Exploratory Data Analysis (EDA) on a cleaned e-commerce dataset and identify useful patterns, trends, and business insights.

The analysis was performed using Python and Pandas, with Matplotlib used for data visualization.

---

🎯 Project Objectives

The main objectives of this project were to:

- Explore the structure and characteristics of the dataset
- Analyze product performance
- Analyze order statuses
- Analyze payment methods
- Analyze referral sources
- Calculate important revenue metrics
- Examine monthly revenue trends
- Analyze quantity sold by product
- Identify top and lowest-performing products
- Create visualizations to communicate findings

---

🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Microsoft Excel
- Python IDLE

---

📊 Analysis Performed

1. Dataset Overview

- Checked dataset shape and column names
- Reviewed the first records
- Examined basic dataset information
- Generated statistical summaries

2. Data Quality Checks

- Checked for missing values
- Checked for duplicate records

3. Product Performance

Analyzed products based on:

- Number of orders
- Quantity sold
- Revenue generated

4. Order Status Analysis

Examined the distribution of orders across different order statuses.

5. Payment Method Analysis

Analyzed the number of orders by payment method and calculated revenue generated through each payment method.

6. Referral Source Analysis

Analyzed order distribution and revenue according to referral sources.

7. Revenue Analysis

Calculated:

- Total Revenue
- Average Order Value
- Highest Order Value
- Lowest Order Value

8. Monthly Revenue Analysis

Analyzed revenue trends across different months using a line chart.

9. Coupon Code Analysis

Examined orders and revenue associated with different coupon codes.

---

📈 Visualizations

The project includes visualizations for:

- Revenue by Product
- Orders by Status
- Revenue by Payment Method
- Revenue by Referral Source
- Monthly Revenue Trend
- Quantity Sold by Product
- Revenue by Order Status
- Revenue by Coupon Code

---

🏆 Key Findings

- Chair was the highest revenue-generating product.
- Chair was also the top-selling product based on quantity sold.
- Phone had the lowest revenue among the products analyzed.
- Phone also had the lowest quantity sold.
- Multiple business dimensions, including products, order status, payment methods, referral sources, and monthly trends, were analyzed to understand overall sales performance.

---

💡 Business Insights

The analysis suggests that:

- High-performing products such as Chair may deserve greater inventory and marketing attention.
- Low-performing products such as Phone may require further investigation into pricing, demand, promotion, or customer preferences.
- Revenue trends can help identify stronger and weaker sales periods.
- Payment and referral-source analysis can help businesses understand customer acquisition and purchasing behavior.

---

✅ Conclusion

This project provided practical experience in Exploratory Data Analysis using Python. The analysis transformed a cleaned e-commerce dataset into meaningful statistics, visualizations, and business insights.

The project strengthened skills in data exploration, aggregation, visualization, and interpretation using Pandas and Matplotlib.
